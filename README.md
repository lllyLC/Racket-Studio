# Racket Studio 

Improved version of Dr Racket for Mac OS, will be updated with time with bug fixes. 

; -----------------------------------------------------------------------------------

Run these commands in terminal to get it working.

1: First install Node.js through :  brew install node 

2:  unzip PreviewPro.zip && cd PreviewPro

3:  npm install

4:  npm run dist

Application can then be found under dist/mac-arm64/Racket Studio.app
Move to Application Folder
